One line under 200 characters that gets you out of work and gets a laugh — a sick-day excuse for the [make.fun bounty](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

## The entry

> My smartwatch says my heart rate hit 190 in my sleep, so I'm taking the day off to check whether I'm a ghost.

109 characters, one sentence, plain text.

## How it runs

`main.py` is a standard-library-only program (Python 3.13). It copies the
pre-written `entry.txt` into the output directory (`MAKEFUN_OUTPUT_DIR`,
default `/output`) as `entry.txt`, byte for byte, so the result is
deterministic across runs.
